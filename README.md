# 海岛碰碰球 · BumpBall

Godot 原生 3D 竞技小游戏。控制踩着大球的小动物，将对手撞出小岛，最后留在岛上的选手获胜。

当前版本：**1.0.27**。

## 运行

使用 **Godot 4.7.2** 标准版打开根目录的 `project.godot`，等待首次素材导入完成后，按 **F5** 运行整个项目。项目使用 Forward+ / Vulkan 渲染。

```sh
godot --editor --path .
godot --path .
```

## 操作与模式

- **WASD / 方向键**：按屏幕方向移动；**Esc**：暂停 / 继续；**F11**：切换全屏；**F2**：调节镜头。
- 开始界面可选择八种动物，按住鼠标左右拖动查看角色。
- **单机模式**：玩家与 NPC 比赛。开场运镜和倒计时结束后开始，无单局时间限制；掉落后可观战、再来一局或返回开始界面。
- 每局及重开从 **20套NPC预设** 中随机抽取，开局不重复：单人5名NPC，联机4名NPC。NPC初始体型／质量、速度倍率均为 **0.75～1.25**，玩家初始能力保持1倍。局中增加NPC也随机抽取，避免与在场NPC重复。
- **联机模式**：一人创建房间，另一人填写房主 IP 和端口加入。使用 ENet / UDP，默认端口 **54130**；远程连接需能访问房主对应 UDP 端口。
- 右侧五个按钮模拟观众互动：变大、变小、加速、减速、侧风。变大 / 变小持续 **8 秒**，其余持续 **3 秒**；也可用数字键 **1–5** 触发。
- 普通移动显示柔和羽化的贴地短拖痕，加速叠加较粗的动态扬尘；减速显示汗珠与摩擦印记。暂停时特效冻结，停止后自然消散。
- NPC礼物在各自初始倍率上加减，遵守既有最终上限；效果结束后恢复该NPC的初始能力。

## 工程内容

- `scripts/`：比赛、碰撞、NPC、联机、角色动画、镜头、UI 与本地存档。
- `scripts/npc_profiles.gd`：20套NPC初始能力；`ground_motion_effects.gd` 与 `motion_effects.gd`：移动特效。
- `assets/animals/`：八种动物的 GLB、实际使用的贴图与头像。
- `assets/ball-prints/`：对应动物的球体爪印。
- `assets/island-v3-refined/`：小岛与装饰模型、贴图、比赛边界几何数据。
- `shaders/`、`materials/`：海面、球体、侧风、贴地拖痕与加速扬尘效果。
- `addons/window_kit/`：统一窗口逻辑。

3D 渲染采用约 1080p 的像素预算，UI 按窗口分辨率显示。首次导入产生的 `.godot/` 是本地缓存；仓库中的 `.import` 和 `.uid` 是素材导入设置与资源标识，需要保留。

## 导出

在 Godot 中安装 **4.7.2 对应的导出模板**，创建 `build/` 目录，然后使用项目提供的 **Windows Desktop** 预设导出。预设使用标准导出模板，无本机绝对路径。

```sh
godot --headless --path . --export-release "Windows Desktop" build/BumpBall.exe
```
